# WCDraft11 ⚽🏆

A browser-based World Cup draft and tournament simulation game.

🌐 Live Demo  
https://wcdraft11.com

## Features

- Random country draft system
- Build your own World Cup XI
- Multiple formations
- Confederation quota system
- Position fit mechanics
- Realistic match simulation
- VAR events
- Turkish / English language support
- Mobile responsive design

## Tech Stack

- HTML
- CSS
- JavaScript
- Netlify
- Namecheap

## Live Project

https://wcdraft11.com

## About

WCDraft11 is an independent football simulation project developed to improve frontend development, game design, simulation logic and deployment skills.
